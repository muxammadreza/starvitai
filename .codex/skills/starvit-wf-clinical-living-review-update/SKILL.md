# Update a living evidence review (NotebookLM summaries + primary papers)

When invoked, follow this workflow as written. Use the Router and relevant role/rule skills as needed, and run the Security/Privacy Gate for tier2+ changes.

## Steps
1) Identify the clinical question.
2) Update search and inclusion criteria.
3) Summarize new evidence:
   - study design
   - population
   - outcomes
   - limitations
4) Update conclusions with certainty grading.
5) Update citations list.

## Output
Updated living review doc + change log.
