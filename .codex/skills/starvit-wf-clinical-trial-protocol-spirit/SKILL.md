# Trial protocol drafting aligned with SPIRIT-style thinking

When invoked, follow this workflow as written. Use the Router and relevant role/rule skills as needed, and run the Security/Privacy Gate for tier2+ changes.

## Goal
Draft a protocol outline that a clinician and IRB can refine.

## Steps
1) Define population, intervention, comparator, outcomes (PICO).
2) Define endpoints:
   - primary
   - secondary
   - safety
3) Define eligibility and exclusions.
4) Define data collection schedule.
5) Define analysis plan at a high level.

## Output
Protocol outline doc + open questions list.
